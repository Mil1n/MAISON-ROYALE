# Maison Royale — Европейская рулетка

Локальное казино на React + TypeScript + Vite, Tailwind CSS и Framer Motion. Только виртуальные фишки, без сервера и платежей.

## Запуск одним HTML-файлом

Откройте `Roulette.html` двойным щелчком в современном браузере. Всё встроено в файл: Node.js, установка пакетов, сервер и интернет для игры не нужны. Проверены автономность ресурсов, вращение и сохранения в Chromium. Прямой запуск через `file://` в облачном браузере заблокирован административной политикой, поэтому именно этот способ запуска здесь не проверен.

Сохранения локального файла зависят от браузера и пути к файлу. Перед переносом или переименованием экспортируйте JSON; импортируйте его после переноса. Если браузер запрещает localStorage для локальных файлов, приложение покажет предупреждение и не начнёт раунд без сохранения.

## Запуск для разработки

Требуется Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
```

Команды выполняются в каталоге проекта. Для точного воспроизведения зависимостей используйте `npm ci`.

```sh
npm test         # проверка правил, выплат, колеса и сохранений
npm run build    # TypeScript, сборка в dist/ и автономный Roulette.html
npm run preview  # просмотр собранного приложения
```

Приложение не использует внешние API, шрифты или изображения. После установки зависимости и сервер Vite работают локально; production-сборку можно раздавать любым статическим HTTP-сервером. Для автономного запуска используйте готовый `Roulette.html`; для разработки — localhost или HTTPS.

## Игра

Выберите фишку (10–5 000), затем нажмите на число, цвет, диапазон из 12 чисел, колонку или другую внешнюю ставку. Каждое нажатие добавляет фишку, резервируя сумму из баланса. До вращения можно отменить последнюю фишку, очистить ставки или заменить их ставками предыдущего раунда. Во время вращения ставки заблокированы.

Стандартные выплаты означают чистую прибыль: число 35:1, 12 чисел / колонка 2:1, остальные внешние ставки 1:1. Возврат включает также саму выигравшую ставку. На зеро проигрывают все внешние ставки. Сплиты, улицы и каре не включены в эту версию поля.

Результат определяется `crypto.getRandomValues` с отбрасыванием смещённых значений. Порядок 37 секторов соответствует европейскому колесу. Результат выбирается перед вращением; вычисленный угол совмещает его сектор с верхним указателем.

## Сохранения

Баланс, ставки, последние ставки, звук и до 10 000 раундов сохраняются в localStorage под ключом `maison-royale-v1`. Последние 20 чисел доступны на столе и в истории. Статистика вычисляется из сохранённой истории и не включает пополнения/сбросы баланса. Победа — раунд с положительным чистым итогом, проигрыш — с отрицательным. Количество ставок означает количество установленных фишек.

Баланс ограничен 1 млрд фишек. Пополнение и сброс доступны через кнопку «+» сверху; сброс баланса требует подтверждения и сохраняет историю. Принятый раунд записывается до анимации и завершается при восстановлении страницы. Повреждённые данные не принимаются; экспорт и импорт JSON позволяют переносить сохранения. Импорт заменяет текущие данные после подтверждения. При недоступном хранилище показывается предупреждение, запуск нового раунда блокируется до успешной записи.

Звуки генерируются Web Audio. Браузер может отключить их при отсутствии поддержки или разрешения на воспроизведение. Сохранение привязано к браузеру и адресу сайта; экспортируйте резервные копии перед очисткой данных.

## Структура

- `src/game.ts` — правила, выплаты, генератор результата и угол колеса.
- `src/storage.ts` — проверка и восстановление сохранений.
- `src/audio.ts` — локальные звуки.
- `src/components/` — колесо и поле ставок.
- `src/App.tsx` — игровой процесс и интерфейс.
- `src/game.test.ts` — тесты правил и сохранений.
