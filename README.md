# 🎰 MAISON ROYALE

### Американская рулетка. Атмосфера казино. Один HTML-файл.

Зелёное сукно, деревянное колесо, латунные детали и фишки, которые хочется поставить на стол. **Maison Royale** — локальная рулетка с анимацией, звуком и полноценным расчётом ставок. Открывай в браузере, выбирай свою стратегию и собирай историю игры.

**🟢 0 и 00 · ⏱️ Автозапуск за 7 секунд · 💸 Своя сумма и All In · 💾 Локальные сохранения**

> 🪙 Только виртуальные фишки. Без платежей, регистрации и аккаунтов.

## ✨ Что внутри

- 🎡 **Американское колесо:** 38 секторов, отдельные зелёные `0` и `00`, правильный порядок чисел и точная остановка под указателем.
- 🃏 **Классическое поле:** числа, красное / чёрное, чёт / нечёт, `1–18` / `19–36`, диапазоны `1–12`, `13–24`, `25–36` и колонки.
- 🪙 **Девять номиналов фишек:** от 10 до 100 000, плюс ввод своей суммы.
- 💸 **All In:** весь свободный баланс на выбранное поле одним следующим нажатием.
- ⏱️ **Автозапуск:** обратный отсчёт на 7 секунд с возможностью перейти на ручное вращение.
- ↩️ **Удобное управление:** отмена последней фишки, очистка поля и повтор предыдущих ставок.
- 📊 **История и статистика:** последние 20 чисел, результаты раундов, чистый итог и крупнейший выигрыш.
- 🔊 **Звуки и анимации:** установка фишек, вращение, выигрыш и проигрыш; звук можно выключить.
- 💾 **Сохранения и резервные копии:** localStorage, экспорт / импорт JSON и проверка повреждённых данных.
- 📱 **Адаптивный стол:** колесо слева и ставки справа на ПК; вертикальная компоновка с прокруткой поля на небольших экранах.

## 🚀 Запуск без установки

1. [Скачай **Roulette.html**](https://github.com/Mil1n/roulette/raw/refs/heads/work/Roulette.html).
2. Открой файл двойным щелчком в современном браузере.
3. Получи стартовые **10 000 виртуальных фишек** и сделай первую ставку.

**Всё необходимое встроено в файл:** интерфейс, логика, стили и шрифт. Для игры не нужны Node.js, сервер или интернет. Звуки создаются прямо в браузере через Web Audio.

> 💡 Сохранения локального HTML зависят от браузера и пути к файлу. Перед переносом или переименованием экспортируй JSON. Если браузер запрещает localStorage для локальных файлов, приложение покажет предупреждение и не запустит раунд без успешной записи.

Автономность ресурсов, игра и сохранения проверены в Chromium. Прямое открытие через `file://` в облачной тестовой среде запрещено административной политикой, поэтому именно этот способ запуска там не проверен.

## 🎮 Как играть

1. **Выбери сумму.** Нажми на фишку или введи положительное целое число в поле «Своя сумма». Пробелы для разрядов допустимы: например, `25 000`.
2. **Поставь на поле.** Нажми на число или зону. Каждое нажатие добавляет ставку и резервирует её сумму из баланса. В одном раунде можно выбирать несколько полей.
3. **Дождись старта или крути вручную.** По умолчанию первая фишка запускает таймер на 7 секунд. Кнопка «Крутить» позволяет начать раньше.
4. **Посмотри результат.** Колесо остановится на выбранном случайном секторе, выигравшие поля подсветятся, а баланс и история обновятся.

### ⏱️ Семь секунд на решение

Дополнительные фишки **не продлевают отсчёт**. Очистка поля или отмена последней оставшейся фишки останавливают таймер. После завершения раунда ставки автоматически не повторяются.

Автозапуск можно отключить переключателем над полем — настройка сохранится. Если перезагрузить страницу с ещё не запущенными ставками, начнётся новый отсчёт на 7 секунд. Во время вращения суммы и ставки заблокированы.

### 💸 Твоя сумма — твой выбор

| Способ | Как использовать |
| --- | --- |
| **Фишки** | 10 · 50 · 100 · 500 · 1 000 · 5 000 · **10 000 · 50 000 · 100 000** |
| **Своя сумма** | Введи целое число от 1 в пределах свободного баланса, затем нажми на поле. |
| **All In** | Нажми **All In**, затем выбери поле — на него пойдёт весь текущий свободный баланс. |

All In использует актуальный остаток; сама кнопка деньги не списывает, а уже сделанные ставки остаются. При нулевом свободном балансе кнопка недоступна. Дробные, отрицательные и превышающие баланс суммы не принимаются.

Пополнить виртуальный баланс можно через **«+»** в верхней панели. Сброс возвращает его к 10 000 фишек после подтверждения, снимает текущие ставки и сохраняет историю.

## 🏆 Ставки и выплаты

| Ставка | Чистая прибыль | Возврат при ставке 100 |
| --- | ---: | ---: |
| Одно число, включая `0` или `00` | **35:1** | **3 600** |
| Красное / чёрное | 1:1 | 200 |
| Чёт / нечёт | 1:1 | 200 |
| `1–18` / `19–36` | 1:1 | 200 |
| `1–12` / `13–24` / `25–36` | 2:1 | 300 |
| Колонка | 2:1 | 300 |

**Возврат включает номинал выигравшей ставки.** Например, 100 на число дают 3 500 прибыли и 100 обратно — всего 3 600. Чистый итог раунда равен всем возвратам минус сумма всех ставок.

🟢 **`0` и `00` — разные исходы.** Каждый выигрывает только на собственную ставку. На обоих зелёных секторах проигрывают все внешние ставки.

Результат выбирается через `crypto.getRandomValues()` с отбрасыванием значений, создающих смещение. Вероятность каждого сектора — **1/38**, преимущество казино для реализованных ставок — **5,26%**. Результат определяется до анимации; угол вращения приводит нужный сектор под указатель.

Сплиты, улицы, каре и ставка на пять чисел не предусмотрены этим полем. Баланс ограничен **1 млрд фишек**: максимально возможная выплата проверяется до принятия ставки и выбора случайного результата.

## 💾 Твоя игра сохраняется

- **В этом браузере:** баланс, текущие и последние ставки, звук, автозапуск и до 10 000 раундов.
- **В истории:** дата и время, сумма ставок, выпавший сектор, возврат и чистый итог.
- **В статистике:** число вращений и установленных фишек, победные и проигрышные раунды, суммы ставок и возвратов, чистый итог и крупнейший чистый выигрыш.
- **В JSON:** экспорт для резервной копии и перенос между браузерами; импорт заменяет текущие данные после подтверждения.

Принятый раунд записывается **до вращения**. Если закрыть вкладку во время анимации, его сохранённый результат будет рассчитан при следующем открытии. Повреждённые сохранения не принимаются; при ошибке записи выводится предупреждение.

Статистика рассчитывается по сохранённой истории и не включает пополнения и сбросы. Победа — положительный чистый итог, проигрыш — отрицательный. Одна ставка в счётчике означает одну установленную фишку.

Прежние сохранения европейской версии совместимы. Ключ localStorage остаётся `maison-royale-v1`; новый сектор хранится строкой `"00"`, отдельно от числа `0`. Перед очисткой данных браузера стоит экспортировать резервную копию.

## 🛠️ Для разработки

**Стек:** React 19 · TypeScript · Vite · Tailwind CSS · Framer Motion · Lucide.

Нужен **Node.js 20.19+ или 22.12+**. Команды выполняются в каталоге проекта:

```sh
npm install
npm run dev
```

Для установки точно по lock-файлу используй `npm ci`.

| Команда | Что делает |
| --- | --- |
| `npm test` | Проверяет правила, выплаты, колесо, лимиты и совместимость сохранений. |
| `npm run build` | Проверяет TypeScript, собирает `dist/` и обновляет автономный `Roulette.html`. |
| `npm run preview` | Запускает локальный просмотр production-сборки. |

Приложению не нужны внешние API или подключённые сервисы. После установки зависимостей разработка работает локально; `dist/` можно раздавать статическим HTTP-сервером.
