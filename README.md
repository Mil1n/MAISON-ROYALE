# 🎰 Maison Royale

**Американская рулетка, которая работает из одного HTML-файла.**

[⬇️ Скачать Roulette.html](https://github.com/Mil1n/roulette/raw/refs/heads/work/Roulette.html)

Локальный игровой стол с зелёным сукном, деревянным колесом и виртуальными фишками. Слева — колесо с 38 секторами, справа — поле ставок. Шарик движется по ободу, замедляется и с затухающими отскоками попадает в карман. Анимация показывает заранее выбранный случайный результат.

🪙 Только виртуальная валюта. Регистрация, платежи и подключение к серверу не нужны.

## 🚀 Запуск

Скачайте `Roulette.html` и откройте его двойным щелчком в современном браузере. Стили, скрипты и шрифт встроены — устанавливать Node.js или подключаться к интернету для игры не требуется.

💰 Начальный баланс — **10 000 фишек**. Пополнение доступно через «+» в верхней панели; сброс баланса требует подтверждения.

## 🎮 За столом

1. Выберите фишку или введите свою сумму.
2. Нажмите на число либо зону поля. Каждое нажатие добавляет ставку и резервирует её сумму.
3. Дождитесь автозапуска или нажмите **«Крутить»**. После остановки обновятся баланс, история и статистика.

⏱️ Первая принятая ставка запускает **7-секундный отсчёт**. Следующие ставки не продлевают его. Очистка поля или отмена последней фишки останавливают таймер. Автозапуск можно выключить; после раунда ставки автоматически не повторяются. При перезагрузке с незапущенными ставками отсчёт начинается заново.

| Сумма | Выбор |
| --- | --- |
| 🪙 Фишки | 10 · 50 · 100 · 500 · 1 000 · 5 000 · 10 000 · 50 000 · 100 000 |
| ✍️ Своя сумма | Положительное целое число в пределах свободного баланса. Можно вводить с пробелами: `25 000`. |
| 💸 All In | Выбирает весь текущий свободный баланс для следующего нажатия на поле. Уже выставленные ставки остаются. |

До вращения доступны отмена последней фишки, очистка и повтор предыдущих ставок. Во время вращения ставки заблокированы. На небольших экранах стол перестраивается вертикально, поле можно прокручивать по горизонтали.

## 🎭 Шуточный вывод

Нажмите **«Вывести»** в верхней панели или **«Вывести фишки»** в окне баланса. Выберите **СБП** или **банковскую карту**, затем укажите положительную целую сумму в пределах свободного баланса.

🦍 Кнопка **«Вывести средства»** откроет картинку с гориллой. Закрыть окно можно кнопкой **«Закрыть»**, клавишей **Esc** или кликом за его пределами.

Это игровой розыгрыш: реальные выплаты не выполняются, виртуальный баланс не меняется.

## 🏆 Правила и выплаты

🟢 Американское колесо содержит числа `1–36` и два отдельных зелёных сектора: **`0` и `00`**. Каждый из них выигрывает только при ставке на него. На обоих зеро проигрывают все внешние ставки.

| Ставка | Чистая прибыль | Возврат при ставке 100 |
| --- | ---: | ---: |
| Одно число, `0` или `00` | 35:1 | 3 600 |
| Красное / чёрное, чёт / нечёт | 1:1 | 200 |
| `1–18` / `19–36` | 1:1 | 200 |
| `1–12` / `13–24` / `25–36` | 2:1 | 300 |
| Колонка | 2:1 | 300 |

Возврат включает саму выигравшую ставку. Чистый итог раунда — все возвраты минус все ставки. Сплиты, улицы, каре и ставка на пять чисел не предусмотрены.

Результат выбирается через `crypto.getRandomValues()` с отбрасыванием смещённых значений. Вероятность каждого сектора — **1/38**, преимущество казино для реализованных ставок — **5,26%**. Движение и отскоки шарика — визуальная имитация, которая не меняет результат и выплаты.

Баланс ограничен **1 млрд фишек**. Максимальная возможная выплата проверяется до принятия ставки и выбора результата.

## 💾 Сохранения

Баланс, ставки, настройки звука и автозапуска, история и статистика сохраняются в localStorage. На столе видны последние 20 чисел, в истории хранится до 10 000 раундов. Принятый раунд записывается до анимации и восстанавливается при повторном открытии страницы. Сохранения прежней европейской версии совместимы.

📤 **Экспорт JSON** создаёт резервную копию. 📥 **Импорт JSON** заменяет текущие данные после подтверждения; повреждённые файлы не принимаются. Перед очисткой данных браузера, переносом или переименованием HTML экспортируйте сохранение.

Доступность localStorage для локальных файлов зависит от браузера и пути к файлу. При ошибке записи приложение покажет предупреждение и не начнёт новый раунд без сохранения. Автономность ресурсов и игра проверены в Chromium; прямой запуск через `file://` в облачной тестовой среде не проверен из-за её политики доступа.

## 🛠️ Разработка

React 19 · TypeScript · Vite · Tailwind CSS · Framer Motion.

Требуется Node.js **20.19+ или 22.12+**. Из каталога проекта:

```sh
npm install
npm run dev
```

Для установки по lock-файлу используйте `npm ci`.

| Команда | Результат |
| --- | --- |
| `npm test` | Проверка игровой логики, выплат и сохранений. |
| `npm run build` | Проверка TypeScript, сборка `dist/` и автономного `Roulette.html`. |
| `npm run preview` | Локальный просмотр production-сборки. |

Правила находятся в [`src/game.ts`](src/game.ts), сохранения — в [`src/storage.ts`](src/storage.ts), интерфейс — в [`src/App.tsx`](src/App.tsx) и [`src/components/`](src/components/). Автономный файл создаёт [`scripts/standalone.mjs`](scripts/standalone.mjs).
